## The engine

`engine.wasm` statically links WebKit (WebCore and JavaScriptCore, largely LGPL-2.1, partly BSD)
with our embedder and the libraries of `deps/`. It is therefore a combined work with an
LGPL-2.1 library. `engine.data` contains fonts (Noto, OFL-1.1), the Mozilla CA bundle (MPL-2.0),
the fontconfig configuration and cache, WebKit's HRTF data `Composite.wav` and our
`wasm-guest.js`; ICU data (Unicode license) is linked into `engine.wasm`.

Further licenses inside the engine, among others: OpenSSL (Apache-2.0), curl, nghttp2, zlib,
brotli, zstd, libpng, libjpeg-turbo, libwebp, expat, libxml2, libxslt, SQLite (public domain),
FreeType, HarfBuzz, fontconfig, woff2, libpsl, Skia (bundled with WebKit), and the Emscripten
runtime (libc, libc++, dlmalloc). Versions and sources: `deps/sources.txt`, `versions.env`.

### When you distribute the engine

Serving `engine.wasm` to users is distributing it. LGPL-2.1 then requires:

- **Notices**: ship `THIRD_PARTY_NOTICES.txt` with the engine (generated by `tools/gen-notices.mjs`
  from `deps/sources.txt`, the WebKit sources and the WebkitWasm notice) and keep it reachable
  from your site.
- **Source offer**: the complete corresponding source of WebKit and the changes. This repository
  is public; the release tag of the engine you serve, with `versions.env` (WebKit commit),
  `engine/patches/`, `deps/` and the toolchain, is that source. Point to it, for example in your
  notices page.
- **Relinking**: users must be able to rebuild the engine with a modified WebKit. The build is
  reproducible from the tag ([build.md](build.md)): pinned toolchain image, pinned WebKit commit,
  patches and dependency recipes with checksums.

If you modify WebKit or the engine yourself, publish your changes under the same terms.

## Packages and server

The npm packages contain only our BSD-2-Clause code. `@browser-lite/server` depends on `ws` and
`ipaddr.js` (both MIT). The relay is our own Wisp implementation; the AGPL-3.0 `wisp-js` server is
not used ([decisions.md](decisions.md) #201). The demo's build tools (Vite and friends) are dev
dependencies and not shipped.

## Reference: WebkitWasm

[WebkitWasm](https://github.com/theogbob/WebkitWasm) by theogbob (BSD-2-Clause, looked at in
October 2026, commit `68c6185`) is a research prototype of WebCore and JSC in WASM with Wisp
networking. It was a reference, not a fork ([decisions.md](decisions.md) #13); three engine
files follow its patterns and keep its notice (see above), which therefore belongs in
`THIRD_PARTY_NOTICES.txt`. Ideas we adopted: the port structure
like the PlayStation port, OpenSSL for the curl backend, building fontconfig and ICU ourselves,
and pinning every dependency. Where we differ: everything is reproducible from this repository,
WebKit changes are many small patches instead of one, the GC never scans WASM locals (#36), and
the transport is an exchangeable interface.
