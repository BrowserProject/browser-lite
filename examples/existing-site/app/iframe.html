Browser in an iframe

The browser page (frame.html) runs in an iframe. The engine needs a cross-origin isolated document, and a frame is only isolated when its parent is too: this page is served with the same COOP/COEP/CORP headers as the browser page. The allow attribute passes the features the browser's services use; for a frame of the same origin most of them are allowed by default, for a frame from another origin (for example a subdomain) all of them, cross-origin-isolated included, are required.
